| 项目                 | 内容                                                                                                                                                                                        |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **产品名称**           | 知道AI学习助手（MemoDeer）                                                                                                                                                                        |
| **一句话定位预期**        | 面向中学生与大学生的AI学习助手：上传知识点即可自动生成针对性习题与记忆口诀，提问时结合用户资料库给出有据可依的解答，让每次复习都像有辅导老师。                                                                                                                  |
| **目标用户**           | 大学生、考研、考公等独立备考者（典型用户：独自学习、缺乏即时反馈和练习素材，手机/电脑学习场景为主）                                                                                                                                        |
| **最大痛点**           | ① 知识点背了忘，没有合适的练习题巩固；<br>② 自学遇到疑问时，搜索答案不准确或缺乏上下文依据，难以判断记忆薄弱点；<br>③ **自学时遇到问题，常因时间不凑巧或身边无人可问，无法及时获得解答，问题积压影响学习进度和信心**。                                                                      |
| **核心功能（已实现）**   | ① **知识库构建**：上传 PDF/DOCX/TXT/MD 文档 → AI（DeepSeek V4-Flash）自动格式化为规范 Markdown → 智能分块 → 向量化入库，支持手动创建 Markdown 笔记。<br>② **智能问答（自动模式）**：系统始终优先从个人知识库检索相关内容，找到时标注引用来源 [1][2]；找不到时自动降级为通用知识回答并注明"非来自笔记"。用户可将回答编辑后保存为笔记。<br>③ **GenUI 知识可视化**：AI 回答中可生成交互式知识组件（概念卡片、对比表格、步骤指南、要点列表、示例框），帮助直观理解知识点。<br>④ **文档全文查看**：上传文档以连续 Markdown 渲染查看，支持从引用链接跳转并高亮定位到对应段落。<br>⑤ **全局搜索**：跨所有笔记本检索，结果按笔记本分组展开。<br>⑥ **笔记管理**：文档/笔记的查看、创建、删除（级联清理向量库）。                                                                                                                                                                                                                                                         |
| **核心功能（规划中）**   | ① **智能出题**：基于知识点一键生成选择题、填空题，配套记忆口诀。<br>② **学习计划 & 进度追踪**：AI 根据知识掌握情况制定个性化学习路径。<br>③ **知识图谱可视化**：知识点关联关系图谱展示。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **技术方案（实际架构）** | **四层协同架构（已落地）**：<br>• **Embedding 层（本地）**：BAAI/bge-small-zh-v1.5（512维），sentence-transformers CPU 推理，零 API 成本，数据不出服务器。<br>• **Flash LLM（API）**：DeepSeek V4-Flash，负责文档 Markdown 格式化、知识点提取等 NLU 任务，轻量快速。<br>• **Pro LLM（API）**：DeepSeek V4-Pro（1M 上下文），负责 RAG 问答推理、GenUI 生成、通用问答，强推理能力。<br>• **向量存储**：ChromaDB 嵌入式，每笔记本独立 Collection，top-k=8 检索。<br>• **前端**：React 18 + TypeScript + Tailwind CSS + react-markdown（含 GenUI 自定义渲染）。<br><br>> 注：原始选题卡中规划的本地 Qwen3-8B RAG 方案暂未部署，当前 RAG 检索阶段使用本地 BGE 向量模型（免费），知识点提取和问答由 DeepSeek API 承担。本地 8B 模型接口已预留（`llm_service.local`），可在获取 GPU 资源后切换到纯本地 RAG。 |
| **我们为什么是最合适做这个的人** | 我本人就是一名学生，亲身经历自学时的种种困境——找不到人问、没有针对性练习、记忆困难，因此最懂这些痛点的真实场景。作为深度用户，我能以学生视角设计产品，确保功能贴近实际学习需求，而不是凭空想象。同时，我具备AI基础知识和产品设计能力，能够将个人经验与技术实现结合，打造真正解决学生问题的产品。                                        |
