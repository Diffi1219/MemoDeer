# 待办事项

## ✅ 已完成

1. ✅ **智能自动问答模式** — 不再需要用户手动选择"知识库模式"或"自由问答模式"。系统默认行为：先检索知识库 → 有结果则 RAG 回答（带引用标注） → 无结果则降级为自由问答（开头说明"笔记中未找到相关内容"，标注"请甄别真伪"）。自由问答内容可保存为笔记（`stream_answer_fallback` + ChatPage "添加到笔记"按钮）。

2. ✅ **前端界面优化** — NotebookPage 重构为 VSCode 风格文件树侧栏 + 分屏布局。文件树支持文件夹层级、新建文件/文件夹、右键菜单、内联重命名。Markdown 文件支持预览/编辑无感切换（带行号）。底部待向量化栏支持一键批量向量化。知识点/卡片/口诀/出题整合为顶部 Tab。

3. ✅ **全局搜索** — `GlobalSearchModal` 组件实现跨笔记本搜索：输入关键词 → `POST /api/search` → 遍历所有笔记本的 ChromaDB → 结果按笔记本分组展示 → 点击展开查看匹配片段 → 点击跳转文档原文并高亮定位。

4. ✅ **Markdown 文档查看与编辑** — `DocumentViewPage` 全屏文档查看（ReactMarkdown 渲染 + 引用高亮滚动定位）。`MarkdownEditor` 组件支持预览/编辑无感切换、行号显示、Ctrl+S 保存、字数统计、向量化状态提示。
